# Welcome to Fusion!

## What is Fusion?

Fusion is a CLI TCG game that lives in your terminal. You can collect and trade cards with other players, as well as the server. We encourage bots that can make trades and buy from the server and auctions.

## Why choose Fusion?

We know there are lots of TCG's out there, but Fusion is the best choice for a tech-y TCG.

| Feature          | Fusion               | Others     |
| ---------------- | -------------------- | ---------- |
| Card numbering   | uint16_t             | Arbitrary  |
| Card naming      | Based on card number | Arbitrary  |
| Theme            | Tech/Computers       | Other      |
| Encourages bots? | Yes                  | No         |
| Runs...          | CLI                  | In the web |
| Has cool docs?   | Yes                  | No         |
